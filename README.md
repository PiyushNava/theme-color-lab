# Theme Color Lab

An interactive Material 3 color playground for comparing a backend-supplied seed color with the semantic colors generated by the Fidelity scheme.

## What you can test

- Backend seed versus generated SDK primary
- Light and dark color schemes
- Contrast from `-1.0` to `1.0`
- Material semantic roles such as `primary`, `surface`, and `outline`
- Primary, secondary, tertiary, neutral, and neutral-variant tonal ramps
- Generated colors applied to realistic interface components
- Click-to-copy HEX values

## Local development

```bash
npm install
npm run dev
```

The development server runs at `http://localhost:3000`.

## Validation

```bash
npm run build
npm run lint
```

## Deployment

Every push to `main` builds and deploys the static site to GitHub Pages.
